# Utdrag (arbeidsnotater)

Korte utsnitt du limer inn for vanskelige passasjer - **ikke** full bok-OCR.

## Filnavn

```
bind-{I|II|III|IV|V}-s{fra}-{til}-{stikkord}.md
```

Eksempel: `bind-III-s142-145-myrens.md`

## Innhold

```markdown
# Bind III s. 142-145

- **Sted/hendelse i JSON:** myrens-verk
- **Formål:** sidetall / formulering

(Kort utdrag eller notat - maks det du trenger for å parafrasere.)
```

`.txt`-filer her er gitignorert. `.md` med korte utdrag kan versjoneres ved behov.
