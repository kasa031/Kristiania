# Supplementære kilder (utenom Bull PDF)

Brukes når appen trenger **flere steder eller presisering**, uten ny full TOC-indeksering.

## Tillatte kildetyper (prioritet)

1. **Oslo byleksikon** (oslobyleksikon.no)
2. **Store norske leksikon** (snl.no)
3. **Riksantikvaren** / Kulturminnesøk (kulturminne-ID)
4. **Museum / institusjon** (f.eks. nationaltheatret.no, vulkanoslo.no)
5. **Lokalhistoriewiki** (sekundær - kryssjekk)

## Regler

- Kort parafrase i `data/*.json` - ikke lange sitater. **Norsk gjengivelse av kilden**, samme mening - ikke tolkning eller oppfunnet tekst.
- `source_ref` kan peke på nærmeste Bull-periode **eller** `pages: "supplement"` med `note` som navngir kilde.
- `verified: true` bare når Karina har sjekket (F5).
- Lag ett notat her: `notater/<sted>.md` med URL og hva som er parafrasert (1/2 side max).
- Ikke nye steder uten koordinat du kan forsvare på kartet.
